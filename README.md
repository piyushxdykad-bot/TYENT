# Tyent India website

A redesign of [tyent.co.in](https://www.tyent.co.in): a static, multi-page site for Tyent water ionizers in India.

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home: cinematic water-ribbon hero, horizontal product collection, technology reveal, "Find your ionizer" quiz, demo booking |
| `about.html` | About Us: story, Tyent India, values, service network |
| `products.html` | Products: comparison table and a section per family (ACE-13, H2-Hybrid, UCE-13 Plus, NMP Series, Q-Series, filters) |
| `why-tyent.html` | Why Tyent |
| `why-water-ionizer.html` | Why Water Ionizer, with an interactive pH scale and FAQ |
| `certifications.html` | Certifications, filterable |
| `blogs.html` | Blog with an in-page article reader |
| `contact.html` | Contact Us and enquiry form |

Shared files: `styles.css`, `site.js` and the `img/` folder.

## Run locally

It is plain HTML, CSS and JavaScript with no build step needed to view it:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy

Works as-is on Vercel, Netlify or GitHub Pages. On Vercel, import the repo and choose **Other** as the framework with no build command; the output directory is the repo root.

## Editing

Every page shares one header, footer and mobile menu, which are generated by `build.py`. To edit content:

1. Change the page body in `src/<page>.main.html` (and its script in `src/<page>.js`, if it has one).
2. Run `python3 build.py` to regenerate all the `.html` files.

Edit `styles.css` and `site.js` directly.

## Before launch

- **Contact details:** phone, WhatsApp, email and office address are marked "to be added" in `src/contact.main.html` and in the footer in `build.py`.
- **Prices:** products show "Price on request".
- **Specifications and certifications:** confirm with Tyent India.
- **Enquiry forms:** these only show a confirmation message for now. Connect them to email, a sheet or a CRM before going live.
